# Hintergrundmusik

Lege hier lizenzfreie Musik als `.mp3` oder `.wav` ab (z. B. von Pixabay Music, Free Music Archive
mit CC0/CC-BY, oder gekaufte Lizenzen). Die Video-Fabrik wählt zufällig einen Track, mischt ihn leise
(-18 dB) unter das Voiceover und blendet am Ende aus. Ohne Datei läuft der Render ohne Musik.

Lizenznachweise bitte als gleichnamige `.txt` daneben legen (`track.mp3` → `track.txt`).
